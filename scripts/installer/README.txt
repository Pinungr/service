RepairShop Manager
Offline repair shop software for Windows

INSTALLATION
This setup includes the application and its runtime. No internet connection,
Python installation or source code is needed on the destination computer.

Choose an installation folder, Start Menu folder and optional Desktop shortcut.
Use Back to review your choices, then Install. The final page can open the app.

FIRST START
Enter your shop details and create your owner username and password.
There is no default production account. Remember the account you create.

UPDATES
Installing an update over an existing installation preserves your shop records.
Close RepairShop Manager before updating or uninstalling.

COMPLETE UNINSTALL
Uninstall through Windows Settings > Apps or Control Panel > Programs and Features.
Uninstall removes the program, shortcuts, uninstall registration and saved local
shop data: customers, repairs, photos, login accounts, settings, logs and backups
inside %LOCALAPPDATA%\RepairShopManager. Saved messaging credentials are removed.
The uninstaller asks you to confirm this permanent deletion.

After uninstalling, reinstalling starts with a fresh shop setup.
Copies you exported to other folders, USB drives or other computers are separate
files and are not searched for or erased by the uninstaller.

This setup is built with Inno Setup: https://jrsoftware.org/
